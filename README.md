# ModelForge-AI-v1 

ModelForge AI is a no-code machine learning application designed to make machine learning simple, fast, and accessible for everyone.

Users can upload CSV datasets, train machine learning models automatically, compare model performances, and export trained models without writing a single line of code.

# ✨ Features

* Automatic dataset problem detection

  * Detects whether the dataset is a Classification or Regression problem

* Automatic feature and target selection

* Supports both:

  * Auto Mode
  * Manual Mode

* Multiple machine learning model training

* Model comparison and ranking based on performance

* Regression evaluation metrics:

  * Mean Squared Error (MSE)
  * Root Mean Squared Error (RMSE)

* Easy trained model export and download

* Simple and user-friendly interface

---

# ⚡ How It Works

## 1. Upload Dataset

Users upload a CSV dataset into the application.

## 2. Choose Training Mode

### Auto Mode

The system automatically:

* Selects features
* Detects target labels
* Identifies the problem type
* Trains multiple machine learning models
* Compares performance results

### Manual Mode

Users manually:

* Select features
* Select target labels
* Choose specific machine learning models for training

---

# 🤖 Machine Learning Workflow

After dataset upload and training:

* The application discovers whether the dataset is:

  * Classification
  * Regression

* Multiple machine learning models are trained automatically

* Models are ranked from best to least based on performance

* Evaluation metrics are displayed on the result dashboard

* Users can instantly download trained models for deployment or future use
